Overview

Multi-user chat system demonstrating networking, GUI programming, and multi-threading concepts in Java.
​
Server handles client connections while clients provide a chat interface for sending/receiving messages.
​
Perfect project to showcase socket programming, event handling, and concurrent programming skills.
​

Features

Server application that accepts multiple client connections and broadcasts messages to all users.
​
Client GUI with chat display area, message input field, and send button for smooth communication.
​
Real-time message delivery with user identification (username display).
​
Clean separation of server and client code for easy understanding and modification.
